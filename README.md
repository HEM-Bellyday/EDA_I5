# Exploratory Data Analysis & Unsupervised Learning

**Statistical Analysis | Data Preprocessing | Multivariate Analysis | Python**

An academic repository documenting practical applications of exploratory data analysis (EDA), statistical methods, and unsupervised learning.

Developed as part of my fifth-year studies in **Data Science and Financial Engineering** at the Institute of Technology of Cambodia (ITC).

## Overview

This repository explores statistical techniques for understanding datasets, identifying patterns, investigating relationships between variables, and preparing data for further analysis.

The work emphasizes both **mathematical understanding and practical implementation** using Python.

## Topics Covered

### 1. Descriptive Statistics
- Quantitative and qualitative variables
- Measures of central tendency and dispersion
- Skewness and kurtosis
- Distribution visualization
- Analysis of the Gapminder dataset

### 2. Bivariate Analysis
- Relationships between variables
- Correlation analysis
- Statistical interpretation and visualization

### 3. Data Preprocessing
- Missing-value identification and treatment
- Outlier detection
- Duplicate observations
- Data quality assessment

### 4. Principal Component Analysis (PCA)
- Data centering and standardization
- Eigenvalues and eigenvectors
- Explained variance and scree plots
- Correlation circles and biplots
- Individual and variable contributions
- Dimensionality reduction and low-rank approximation
